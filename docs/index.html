O teu semestre inteiro.
Um só ecrã. Zero confusão.

Um dashboard académico que corre no teu computador, guarda os teus dados num ficheiro só teu, e mostra tudo o que precisas de saber sobre o semestre: o que estudar, quando entregar, quanto falta e qual a média.

Funcionalidades

Tudo o que precisas.
Nada do que não precisas.

Doze funcionalidades pensadas para o dia-a-dia de um estudante da UAb. Cada uma resolve um problema concreto.

📊

Resumo Académico

Abres a app e vês logo tudo: progresso da licenciatura, média ponderada, UCs em frequência, concluídas. Zero cliques, zero cálculos.

Homepage
📅

Calendário Inteligente

Um calendário mensal onde vês quando abrem e fecham as atividades. Cada UC tem a sua cor. Filtra, esconde o que já entregaste, vê o mês todo.

Timeline visual
🗺️

Roteiro Semanal

As 17 semanas do semestre decompostas numa timeline. Tópicos de cada UC, aberturas, prazos e checkboxes. A semana atual fica destacada.

Plano de estudo
📋

Atividades Sumativas

Uma tabela limpa com todas as entregas. Ordena por UC, nome, data ou cotação. Marca como entregue num clique. Ajusta datas se o professor mudar algo.

QG de entregas
📘

Dossiê do PUC

Importas o PUC e a app guarda tudo: apresentação, resultados de aprendizagem, metodologia, condições de aprovação, bibliografia, calendário oficial.

Fonte da verdade
🤖

Importação via IA

Botão que copia uma prompt pronta. Colas no ChatGPT/Claude/Ollama com o PDF. A IA devolve JSON. Carregas. Tudo integrado em 3 minutos.

3 minutos
🔔

Alertas de Prazos

Configuras a antecedência. Quando um prazo se aproxima, aparece um toast. Urgente? Fica vermelho. Silencia ou silencia para sempre.

Notificações
🎨

Dark e Light Mode

Botão no canto. Preferência guardada. Para quem estuda de noite, isto não é detalhe — é qualidade de vida.

UI
💾

Armazenamento Configurável

Aponta o data.json para onde quiseres: PC, Google Drive, NAS, OneDrive. Trocas de pasta? A app pergunta antes de mexer.

Local-first
🛡️

Backup Automático

Antes de qualquer operação sensível, o ficheiro antigo é preservado. Guarda os últimos 5. Podes estragar tudo — recuperas sempre.

Segurança
📥

Backup Manual

Um clique descarrega todo o teu estado num JSON. Portátil morreu? Importas noutro PC e continuas.

Portabilidade
⚡

Zero Instalação

Sem base de dados. Sem Docker. Sem npm install. Copias o app.py, corres python app.py, está a funcionar.

Zero-config
